# SmartDiet+ 🥗

An AI-powered diet and calorie tracking platform that provides personalized meal recommendations, calorie monitoring, and exercise suggestions.

## Features

- Personalized Diet Recommendation
- Calorie Tracking
- Exercise Suggestions
- MySQL Database Integration
- User Profile Management
- Interactive Dashboard

## Tech Stack

- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript

## Installation

```bash
pip install -r requirements.txt
python app.py
